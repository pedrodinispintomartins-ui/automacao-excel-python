# Automação de Relatórios de Vendas e Gestão de Cobranças

Este projeto em Python automatiza o processamento de dados de vendas de empresas e gera relatórios executivos e ficheiros Excel para cobrança de pagamentos pendentes.

##  Funcionalidades
- Leitura e processamento automático de dados de vendas.
- Separação automática de vendas pagas vs. pendentes.
- Cálculo de totais faturados e montantes em dívida.
- Exportação de ficheiros Excel formatados para a equipa financeira.

##  Tecnologias Utilizadas
- **Python 3.14**
- **Pandas** (Tratamento e análise de dados)
- **OpenPyXL** (Geração de ficheiros Excel)
